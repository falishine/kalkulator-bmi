# Cara Menjalankan Kalkulator BMI

1. Buka project Kalkulator BMI menggunakan Apache NetBeans IDE 25.
2. Pastikan konfigurasi JavaFX dan dependensi Maven sudah tersedia dengan benar.
3. Lakukan Clean and Build untuk memeriksa dan membangun project.
4. Jika proses build berhasil, jalankan aplikasi melalui Maven dengan perintah javafx:run.
5. Tunggu beberapa saat hingga tampilan kalkulator muncul.
6. Isi kolom nama, berat badan dalam kilogram, dan tinggi badan dalam sentimeter.
7. Tekan tombol HITUNG BMI untuk mengetahui nilai BMI beserta kategori berat badan.
8. Gunakan tombol RESET jika ingin mengosongkan data dan melakukan perhitungan baru.
